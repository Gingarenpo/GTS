# はじめに

本書は、GTS - Ginren Traffic System（以降、GTSとします）における利用者向けのユーザーマニュアルとなります。もし、GTSの開発者ならびに拡張パックの製作者としての利用をご希望の場合は、別途用意している仕様書の方をご覧ください。こちらでは、Modの使い方と追加されるものの紹介に留めています。

なお、開発を進めるうえで予告なく仕様を変更する場合があります。その場合、本書と現況が一致しないことがあります。その際は、現況を優先して下さい。なるべく本書も最新版の仕様に追従するように修正を行っていく予定ですが、開発と同時並行で抜け落ちることが多々あります。

また、このドキュメントはマークダウン方式で記載したものをWordに自動変換することでPDF化をしています。そのため、体裁などお見苦しい点が多々ありますが、管理の効率化のためご了承ください。マークダウンを見ることができる方は、直接マークダウンの方を見たほうが早いかもしれません。

## GTSって？

GTSは、Minecraftの世界（ワールド）に「（道路）交通」の概念を与えるModとなっています。MinecraftのModとして、「鉄道」「道路（情景）」に関するModは多々既に存在していましたが、銀河連邦（以下、開発者）は一信号機ファンとして「Minecraftにも信号機をリアルで生やしたい」という思いがありました。そこでGTSを製作するに至ったものとなります。

詳しくは後述しますが、上記の通り主に「交通信号機」に付随したブロックを追加します。各機器はMQOファイルを用いてリアルな描画を行うことができます。

GTSは、以下のModと親和性が非常に高いです。

- RealTrainMod（ngt5479氏製作）　…　Minecraftに鉄道の概念を与えるModですが、拡張パックが非常に充実しており、こちらでも信号機を軽く動かすことができます。GTSは、RealTrainModの拡張パックを参考にさせていただいています。
- AsphaltMod（Muka2533氏製作）　…　Minecraftに道路情景を司る様々なアイテムを追加するModです。こちらも信号機はありますがおまけ程度の要素でしかないらしい……？

上記のModは全てGTS内で動作を確認しており、競合は今のところ発生していません。安心してご利用いただけます。

## GTS1.xとGTS2.xについて

GTSは、1.x系列と2.x系列の2つがあり、**互換性がありません**。1.xは2025年6月30日をもちましてサポートを終了しているため、本書では特記すべきことがない限りGTS2.xに関する情報となります。1.xを継続して使用する場合は旧版のドキュメントを参考にしてください。ただし、**サポートはありません**。

## 拡張パックについて

GTSでは、ほぼすべての追加されるブロック（アイテム）に関して、拡張パックをサポートしています。これにより、各交通機器のモデルを自由に変更することができます。拡張パックの使い方については後述します。また、拡張パックの作成に関する情報は別途用意している仕様書をご覧ください。

なお、一度入れた拡張パックはそれを使用しているワールドで遊ぶ際は必ず入れてください。さもなくば全部ダミーモデルに化けます（落ちはしないはず）。

## 推奨スペックとバージョン

GTSは単なるブロックの世界を超えてリアルなモデルを描画します。その関係上、（拡張パックによりますが）通常のMinecraftよりやや高いスペックを要求されます。また、対応バージョンは現時点で**1.12.2**のみとなります。もしかしたら1.10.2～1.11くらいまでも動くかもしれませんが、公式に動作を検証したのは1.12.2のみとなりますので、それ以外のバージョンのサポートはないと思ってください。なお、1.13.x以降の対応は構想段階であり、1.7.10の対応は行わない予定です（できることが少なすぎるのできつい）。

以下、大体ストレスなく動作できると思われる推奨スペックとなります。

|項目|推奨スペック|備考|
|---|---|---|
|CPU|第8世代Core i3以上|CPU自体はそこまで要求されませんが複雑な制御を大多数の場所で実施すると重くなるかもしれません。|
|GPU|RTX2060以上|GTS2.0以降はそこまで重くなくなりましたが、それでも大量に設置する場合はGTXグラボでは心もとなく、オンボードグラフィックではかなり厳しいかと思われます。|
|RAM|16GB以上、Java割当3GB以上|GTS2.0以降はメモリ管理を整理したので3GBあれば問題ないと思いますが、大量のパックを入れる場合は4GBは確保しておくといいです。|

ここ読んでいる方はわかっているとは思いますが、**BE（統合版）は非対応です**。Java Editionを使用してください。BEへの対応予定は一切ありません。

## マルチプレイについて

現時点でマルチプレイは想定していません。もしマルチプレイを行う場合は参加する全員が同じ拡張パックを入れる必要がありますが、動作確認していないのでそもそも落ちる可能性もあります。需要があれば対応します。

# 導入方法

GTSは、Minecraft Forgeを前提Modとして要求します。そのため、事前にMinecraft Forgeをインストールしておいてください。こちらの導入方法に関しては割愛させていただきますが、LATESTとRECOMMENDEDはどちらでも動作します（開発環境ではLATESTを使用しています）。

以下、Minecraft Forgeをインストールしたとして、手順を掲載しています。

## GTSのModファイルをダウンロードする

2025年6月30日現在、GTSのModファイルは以下の場所からダウンロードすることができます。

- <a href="https://ginren.info/G-Factory/">公式サイト</a>（推奨）　…　銀連製作所（以降、当社）の公式サイトから、ダウンロード可能なすべてのファイルをダウンロードすることが可能です。
- <a href="https://github.com/Gingarenpo/GTS">GitHub</a>　…　ソースコードの公開と、**リリース版**の提供を行っています。アルファ版、ベータ版、プロト版の公開は行っていません。
- <a href="https://www.curseforge.com/minecraft/mc-mods/gts-ginren-traffic-system">CurseForge</a>（非推奨）　…　一応いくつかファイル公開していますが、あまりこちらの更新は行わないのでこちらからのダウンロードは非推奨となります。

上記から、GTSのModをダウンロードして、お使いのMinecraftの`Mods`ディレクトリの中にそのまま入れてください。通常のForge Mod導入時の方法と特に変わりはありません。

## GTS用のディレクトリを作成する

一度起動すると勝手に作成されるようにしていますがうまくいかないケースが存在するので、あらかじめ作成します。`mods`ディレクトリ直下に、`GTS`というディレクトリを作成してください。このディレクトリは、GTSが他Modと競合せずに拡張パックなどを扱う上で必要となりますので、必ず作成してください。

## Minecraftを起動する

あとは、Minecraftを起動してください。起動後、タイトル画面が表示されたら`Mods`をクリック、Modの中身に`GTS - Ginren Traffic System`があれば導入成功となります。

途中で落ちた場合はクラッシュレポートを基に読み取る作業が必要となります。これに関しては末尾にまとめます。

## 遊ぶ前に……

ワールドのバックアップを取ることを強くお勧めします。`saves`ディレクトリ内にワールドに関する情報がディレクトリとして格納されているので、こちらをまとめてZip圧縮し、バックアップを保存しておきましょう。当社は、GTSを導入したことによりデータの破壊・消失などが発生しても責任を負いません。

## 拡張パックを入れたい場合

拡張パックはZip形式となっているはずなので、そのZipファイルを**解凍せずにそのまま**`GTS`ディレクトリに置いてください。正しい拡張パックであれば、次回起動時に読み込まれます。

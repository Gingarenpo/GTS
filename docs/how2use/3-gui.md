# モデル選択画面の見方

基本的に、各ブロック（拡張パックによるモデルの変更に対応しているブロック）においてはモデル選択画面を開くことになります。この画面はどのブロックも共通ですが、右上の部分は各ブロックに固有の設定項目となっています。画面を最大化にするとボタンのテクスチャがバグるのは今後どうにかしたいところです。

## 共通部分（左側）

左側は、モデル選択を行うことができる共通部分となっています。

### モデルプレビュー

ここには、現在選択されているモデルのプレビューが表示されます。なんかぐるぐる回ります。基本的に画面内に収まるようになりますが、あまりにもでかいものははみ出ます。また、ほぼ全オブジェクトが表示されてしまうので、ポールとかアームが変なことになりますが気にしたら負けだと思います。

### モデル選択スクロールボックス

GTSが読み込んだ全拡張パックの中からそのブロックに適したモデルがここに一覧表示されます。この一覧表示から、お目当てのモデルを探してクリックすることでそのモデルを選択状態にできます。選択状態にすると背景が緑色に反転するので、その状態で「モデルを確定」をクリックしてください。これでモデルプレビューが更新され、モデルが変更されます。

なお、モデルを変更した場合、そのモデルでデフォルトでセットされている座標・回転情報が上書きされるため、再度座標・回転の位置調整を行う必要が生じますのでご注意ください。

## 共通部分（右下）

右下には、各モデルの座標（描画位置）や回転角度を指定することができます。小数点を使用することができます。小数として無効な数値を入力すると「座標の確定」をクリックしても赤文字になり反映できません。

座標はそのブロックが設置された場所の中央（0.5, 0.5, 0.5）を原点とみなしたときの相対的な移動座標を指定します。alpha3まではグローバル座標になっていたため、XZ軸の移動がおかしなことになっていましたが、alpha4よりローカル座標に変更したため、直観的に座標移動できるようになっています。

回転はalpha4から追加されたもので、設置初期の角度からの変更ができます。Y軸も変更できますがこちらはプレイヤーの向きに応じて自動で変化するのでそこまで変更する必要はないかと思います。交通信号機でルーバーなどを再現する際に、X軸を調整することで誤認防止を高めたりできます。Z軸は……何に使うんだろう？

## 交通信号機（右上）

交通信号機の場合、右上は以下の項目が出現します。

### チャンネル名

交通信号制御機で使用するチャンネル名を入力します。チャンネル名は大文字小文字を区別します。アタッチされた制御機がある状態で、アタッチされた制御機に存在するチャンネル名を入力するとその時点で動作が開始します。アタッチされた制御機が存在しない場合や、その制御機に存在しないチャンネルであっても入力はできますが、何も光りません。チェックする機能は特に入れていないので、各自でチェックをしてください。

## 交通信号制御機（右上）

交通信号制御機の場合は、サイクルのロード・ならびにセーブができるようになっています。

## 交通信号柱（右上）

alpha4現在、交通信号柱においては設定項目はありません。

## 押ボタン箱（右上）

alpha4現在、押ボタン箱においては設定項目はありません。

## アーム（右上）

alpha4現在、アームにおいては設定項目はありません。

# 表示板設定画面の見方

モデルを選ばない分、表示板の設定画面はやや特殊になっています。alpha4時点では、地名板の生成のみを可能としているので、その点に絞って解説します。

## テクスチャプレビュー（左上）

現在適用されているテクスチャのプレビューが表示されます。テクスチャそのものなので地名板ではないのですが、おおむねどのようになっているのかを確認することができます。

## フォント選択（左下）

日本語部分、英語部分のフォントを指定できます。現在、GUI内でフォントを検索する機能はなく、フォント名を手動で入力する必要があります。フォント名は内部で使用しているもので、よくわからない場合は右側にある「フォント一覧をログに出力」をクリックすることで、ゲームログに使用可能なフォント一覧が出力されるのでそこから入力してください。

なお、フォントによっては変な位置に出力されたり、そもそも表示されないことがあります。その場合はそのフォントの使用は諦めてください。

## 各種表示内容設定（右上）

地名板として表示するための設定項目です。

### 日本語・英語部分

その名の通りで、日本語部分と英語部分の文字を入力します。なお、便宜上そうしているだけで英語部分に英語しか入れてはならないというわけではありません。うまく使えばいろいろ再現できます。

### 文字色・背景色

文字色と背景色をそれぞれカラーコード（♯から始まる6文字のコード）で記載します。カラーピッカーは用意していないので手動で入力してください。カラーコードとして不適切なものを入れると変更を反映できずに赤文字になります。よく使う色を以下に置いておきます。

- #ffffff …　白
- #ff0000 …　赤
- #00ff00 …　緑
- #0000ff …　青
- #800000 …　茶色（山梨とかで使われている色）
- #000000 …　黒

### 幅固定？

これにチェックを入れると、幅固定地名板になります。チェックを外すと、幅合わせになります。幅合わせの場合、次に出てくる「幅」は完全に無視されます。

幅固定と幅合わせの違いは、文字に合わせて幅をあわせるか固定するかの違いです。幅固定にすると文字がどんどんつぶれる・伸びていきます。幅合わせにすると、文字を基準に幅を自動で調整します。この際、高さを基準に幅を指定することになります。

よくわかんない人はとりあえず幅固定にしておけばいいと思います。

### 幅・高さ・深さ（厚さ）

大きさを小数で指定します。小数として不正な値を入れると赤文字になりエラーになります。負の数のチェックは入れていないので負の数を入れるとクラッシュする可能性があるため、ここに負の値は入れないでください。

前述の通り、幅合わせにした場合はここで指定した幅は無視されます。

### 右下部分

ここは座標・回転の指定なのでモデル選択GUIと共通です。
